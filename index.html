Feito para quem vende fiado

Você assina o Acerto, cadastra seus clientes e lança o fiado de cada um. O cliente não precisa de conta nem de aplicativo.

Como fica no dia a dia

Na padaria. Seu João leva R$ 10 de pão e combina de pagar no mês que vem. Você lança no nome dele, com o vencimento, e o saldo fica guardado.

Na lanchonete. Você cadastra a Dona Marta e anota R$ 20 de pão no nome dela. Quando ela voltar para pagar, você dá baixa.

O que você faz no Acerto

  • Cadastra cada cliente uma vez e usa sempre
  • Lança o fiado: o que levou, o valor e quando vai pagar
  • Vê quanto cada cliente deve e o total a receber da loja
  • Acompanha os maiores devedores e os próximos vencimentos
  • Dá baixa quando pagam e mantém o histórico de cada cliente

Feito para todo mundo ler. Alto contraste e ajuste do tamanho da fonte (A− / A+) ficam sempre no topo da tela.

Dúvidas frequentes

Meu cliente precisa ter conta?

Não. Só a loja usa o Acerto. Você cadastra o cliente e lança o fiado dele.

Preciso instalar alguma coisa?

Não. O Acerto abre no navegador, no celular ou no computador.

Meus dados ficam salvos?

Nesta versão, ficam guardados no navegador do aparelho que você usa. O armazenamento na nuvem está nos planos para as próximas versões.

O Acerto cobra ou recebe pelo meu cliente?

Não. Ele registra quanto cada cliente deve. O pagamento continua sendo combinado entre você e o cliente.

Posso trocar de plano depois?

Sim. Você pode começar no Essencial e passar para o plano Loja quando a sua carteira de clientes crescer.

Como Funciona

Entenda o sistema Acerto

O que é o Acerto?

É um sistema para controlar compras feitas "no fiado" — ou seja, compras realizadas agora para pagamento posterior. O cliente registra a compra e acompanha quando precisa pagar. O proprietário acompanha quem deve e quanto.

Como a loja cadastra um cliente?

  1. Acesse "Cadastrar Cliente" no menu de Pagamentos
  2. Preencha os dados do cliente (nome, WhatsApp, CPF, idade, rua) e o que ele levou (descrição, valor, datas)
  3. Clique em "Salvar Cliente"
  4. Acompanhe quanto ele deve em "Histórico" ou "Próximos Pagamentos"

Como o proprietário usa?

  1. Acesse "Administração" no menu lateral
  2. No Dashboard, veja o total a receber e os maiores devedores
  3. Em "Valores a Receber", veja o detalhamento por cliente
  4. Em "Clientes", gerencie o cadastro de compradores

Acessibilidade

Este sistema possui dois mecanismos de acessibilidade no topo da tela:

  • ◑ Contraste — alterna entre modo normal e alto contraste
  • A− / A+ — diminui ou aumenta o tamanho das fontes do site
ℹ️ Sobre o banco de dados: Futuramente, o sistema poderá ser integrado a um banco de dados para armazenar clientes, compras, pagamentos e históricos de forma permanente. Nesta versão, os dados são temporários e ficam armazenados no navegador (localStorage).

Perguntas Frequentes

Dúvidas mais comuns sobre o sistema

Os dados ficam salvos?

Nesta versão, os dados ficam temporariamente no navegador (localStorage). Em versões futuras, serão integrados a um banco de dados real.

Posso usar no celular?

Sim! O sistema é responsivo e funciona em celulares, tablets, notebooks e computadores.

Como faço login?

O módulo de login e cadastro será implementado por outros integrantes do grupo em uma próxima etapa. Por ora, o sistema funciona sem autenticação.

Quem pode usar a área administrativa?

Atualmente, a área administrativa é acessível a todos para fins de demonstração acadêmica. Futuramente, será protegida por login de administrador.

Como mudar o contraste?

Clique no botão "◑ Contraste" no canto superior direito. Clique novamente para voltar ao modo normal.

ℹ️ Projeto Acadêmico: Este sistema é um projeto acadêmico em desenvolvimento. Login, cadastro e banco de dados serão implementados em etapas futuras pelos demais integrantes da equipe.
